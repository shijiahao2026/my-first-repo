# my-first-repo

我的第一个 GitHub 仓库 —— 用来练习 GitHub Desktop 的完整流程。

## 这是什么

一个最简单的静态网页 + 练习用仓库，用来熟悉：
- 创建 / 克隆仓库
- 修改文件并提交（Commit）
- 推送到云端（Push）
- 用 GitHub Pages 发布成公开网页

## 目录结构

```
my-first-repo/
├── index.html      # 网页首页
├── README.md       # 项目说明（你正在看的文件）
└── .gitignore      # 告诉 Git 哪些文件不要上传
```

## 如何使用

1. 双击 `index.html`，用浏览器打开即可预览
2. 修改文字后，在 GitHub Desktop 里写一句说明并点 `Commit to main`
3. 点 `Push origin` 同步到 GitHub
4. 在 GitHub 网页端 `Settings → Pages` 选择 main 分支，即可获得公开网址
